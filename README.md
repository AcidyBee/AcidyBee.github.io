# acidybee.github.io

Portfolio d'Alexis Bourgeois (AcidyBee) : data scientist senior et biostatisticien.
Site statique bilingue (FR / EN) en un seul fichier `index.html`, sans dépendance ni étape de build.

- `index.html` : le site (HTML, CSS et JavaScript)
- `img/` : figures des études de cas
- `favicon.svg` : icône hexagonale

Mettre à jour : modifier `index.html`, puis commit sur `main` ; GitHub Pages republie en une à deux minutes.

La carte en hexagones de la page d'accueil est produite par le projet [pav-grenoble-hexbin](https://github.com/AcidyBee/pav-grenoble-hexbin).
